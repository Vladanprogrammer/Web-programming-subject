# Мої 3 найкращі міста світу

Навчальний статичний багатосторінковий web-сайт (лабораторна робота №1 з дисципліни «WEB-програмування»).

## Опис

Блог про три міста: Париж, Токіо та Прага. Для кожного міста створено окрему сторінку з описом,
цікавими фактами, визначними місцями та особистою оцінкою. Також є сторінка з HTML-формою «Запропонувати місто».

## Структура проєкту

```
my-best-cities/
├── index.html
├── city-paris.html
├── city-tokyo.html
├── city-prague.html
├── form.html
├── images/
│   ├── paris.jpg
│   ├── tokyo.jpg
│   └── prague.jpg
└── README.md
```

## Технології

HTML5, Git, GitHub, GitHub Pages.
